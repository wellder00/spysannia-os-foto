# Списання ОС ГМЗ — довідник карток/фото (мобільне зеркало)

Статична копія застосунку лише для вкладки «Картки ОС» — щоб відкривати фото
з телефона будь-де, без локального сервера.

- Фото стиснуті (макс. 1280px, JPEG 75%) для швидкого завантаження на мобільному інтернеті.
- Вкладки «Позиции», «Вопросы», «Документы», «Общие данные» показують статичний
  знімок бази на момент публікації — **не** синхронізовані з робочим Artifact
  на claude.ai. Для роботи з журналом списання користуйтесь Artifact, тут —
  тільки перегляд карток і фото.
- Доступ закритий паролем (клієнтський захист, не є надійним шифруванням —
  не публікуйте це посилання).

Згенеровано з spysannia-os (`build_photos.py`, `build.py`), дивись CLAUDE.md у вихідному репозиторії.
